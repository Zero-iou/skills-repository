# 无参考图自动风格迁移指南

用途：当用户只提供原图、没有参考图时，根据图片自身题材、光影、色彩和失败风险，自动选择提示词库中的风格卡，生成 A/B/C 三个审美调优版本。

## 核心原则

无参考图时，不要假装存在参考图。此时任务不是“参考图像素级迁移”，而是“基于图片判断的自动风格迁移”：

1. 先判断原图适合什么风格，而不是用户想要什么风格。
2. 从提示词库中选择最合理的目标风格卡。
3. 只迁移光影、色彩、质感和局部保护策略，不改变画面内容。
4. 输出 A/B/C 三个强度版本，默认推荐 B_standard。
5. 报告中明确写：参考图为空，使用自动风格迁移。
6. 所有输出必须来自对原图的实际像素修改，不能重新生成一张图片替代原图。
7. 所有评分必须来自真实输出图分析，不能凭提示词或审美预期打分。
8. 如果原图是 RAW，必须先真实显影为 16-bit TIFF，再做自动风格迁移和评分。

## 自动选择流程

```text
输入：一张原图，无参考图

1. 图像判断：
   - 题材
   - 主体
   - 光源方向
   - 影调类型
   - 对比类型
   - 主色/辅色/点睛色
   - 空气感
   - 关键材质
   - 视觉路径
   - 需要保护的区域
   - 主要失败风险

2. 风格候选：
   根据判断结果，从风格卡中选出 2-3 个候选。

3. 风格打分：
   对每个候选风格打分：
   - 题材匹配：0-25
   - 光源匹配：0-20
   - 影调匹配：0-20
   - 色彩匹配：0-15
   - 材质匹配：0-10
   - 失败风险低：0-10

4. 选择：
   最高分作为主风格。
   如果第二名与第一名差距 <= 8 分，可作为辅助风格。
   如果风格之间冲突，只保留主风格。

5. 组合提示词：
   主风格卡 + 曲线卡 + 色彩配方卡 + 局部保护卡 + 失败回退卡。

6. 生成：
   A_light、B_standard、C_strong。

7. 验收：
   无参考图时不计算参考 RGB 误差；改为计算技术检查、9 点前后采样、提示词匹配度和一票否决。
```

## 无参考图评分

无参考图时不要输出“参考图迁移分”。改为输出：

- `prompt_fit_score`：提示词匹配度，目标 `>= 90`
- `lighting_quality_score`：光影质量，目标 `>= 90`
- `color_quality_score`：色彩质量，目标 `>= 90`
- `protection_score`：局部保护，目标 `>= 90`
- `technical_check`：高光、黑位、饱和度、噪点、过锐检查

这些分数必须基于真实文件计算：

- 读取原图和 A/B/C 输出图的实际像素。
- RAW 输入时，读取显影后的 16-bit TIFF 和 A/B/C 输出图的实际像素，并在评分文件记录 RAW 解码过程。
- 计算亮度分布、黑位/白位剪切比例、对比度、饱和度、色偏、局部保护区域变化。
- 读取 9 个采样点的前后 RGB 值。
- 检查输出图尺寸、格式和文件路径。
- 将评分依据写入 `scores.json`，将采样坐标和值写入 `rgb_sampling.csv`。

禁止：

- 根据提示词直接给 `90+` 分。
- 根据肉眼主观判断伪造量化分。
- 未读取输出图就填写评分。
- 使用生成模型重画一张图后冒充调图结果。

仍然执行一票否决：

- 高光爆掉
- 阴影死黑
- 肤色偏绿或偏灰
- 绿色变脏
- 天空假蓝
- 橙黄主体丢失
- 明显滤镜感

## 回退规则

如果自动选择后的结果不自然：

- 风格过强：降低 C_strong 强度，回到 B_standard 附近。
- 暗部太死：减少黑场压暗，恢复浅阴影和主体边缘。
- 天空假蓝：降低蓝色饱和，恢复灰度和云层层次。
- 绿色脏：降低青色污染，恢复黄绿/深绿分层。
- 主体不突出：增加主体局部 dodge，压低无关背景。
- 像滤镜：减少全局色相覆盖，改为亮度区间和局部 mask。
