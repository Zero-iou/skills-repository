# 参考相册风格提示词库

来源：`Shainblum摄影相册_1097张.pdf` 全量页面缩略图分析。  
分析范围：1205 页渲染页，其中包含摄影作品页、章节页、教程截图、器材页和少量重复示例页。提示词只提取可迁移的摄影/调色特征，不直接要求模仿某位在世摄影师姓名。

## 全量视觉统计摘要

- 主体风格：风光、海岸、山地、森林、火山、城市夜景、沙丘、冰雪、雾景、星空、极光、长曝光水流。
- 整体影调：低调和中低调为主，暗部占比高；大量画面通过局部高光建立视觉中心。
- 对比倾向：高对比、强明暗分离明显；常见“深暗前景 + 高亮天空/熔岩/城市灯/水面反光”。
- 色彩倾向：冷蓝/青蓝占多数，金橙/琥珀暖调紧随其后；很多作品使用冷暖对冲。
- 饱和度：整体中等偏克制，关键色局部饱和；避免全局高饱和滤镜感。
- 高频风格标签：
  - 冷蓝青调、雾化山海、冰雪瀑布、夜空银河
  - 金橙夕阳、沙丘纹理、城市蓝橙、火山熔岩
  - 湿润森林、苔藓绿色、长曝光水流
  - 黑白/低饱和雾景、高反差剪影

## 通用母提示词

用于描述目标审美，不绑定具体照片：

```text
将原图调整为电影感风光摄影调色：整体中低调，高光集中而不爆，暗部深但保留纹理；先建立清晰的明暗层次，再进行色彩迁移。色彩以冷蓝/青蓝阴影与金橙高光形成冷暖对比，饱和度克制，局部关键色有力量但不过度艳丽。保留空气透视、雾气层次、水面或云层的柔和过渡，增强主体边缘光和视觉中心。避免套滤镜感、HDR 脏灰感、天空假蓝、绿色发脏和阴影死黑。
```

## 风格族 01：冷蓝雾化山海

适用图像：山脉、海岸、瀑布、冰川、雾景、阴天风光。

```text
目标风格：冷蓝雾化山海。降低整体色温，阴影偏蓝青，中间调保留自然灰蓝，高光保持柔和银白。压低黑位但不堵死暗部，在山体、海面、云雾之间保留细腻层次。提升局部对比和微清晰度，但让远景雾气保持柔软。水面和云层使用平滑长曝光质感，天空避免过饱和蓝色，整体呈现安静、深远、湿润、电影感的冷调风光。
```

关键调图词：

- 阴影：冷蓝、青灰、深而有细节
- 中间调：低饱和蓝灰、雾化过渡
- 高光：银白、柔和、轻微暖边缘
- 禁忌：青色溢出、天空假蓝、雾气变脏、山体死黑

## 风格族 02：金橙逆光与日落

适用图像：日出、日落、逆光花草、海岸落日、山地霞光、城市晨昏。

```text
目标风格：金橙逆光。让高光呈现温暖金橙色，保留太阳附近的亮度层次，不让高光纯白爆掉。阴影保持深蓝或深紫灰，形成冷暖分离。增强逆光边缘、空气中的颗粒感和远景霞光，但控制全局饱和度，避免整张图变橙。主体暗部需要有形体和纹理，前景可以略暗以制造纵深。整体效果应温暖、宏大、有层次，而不是黄色滤镜。
```

关键调图词：

- 阴影：深蓝、紫灰、压暗但保留轮廓
- 中间调：暖褐、琥珀、柔和渐变
- 高光：金橙、日晕、边缘光
- 禁忌：高光爆、全局泛黄、肤色蜡黄、绿色发黄发脏

## 风格族 03：低调火山/熔岩/夜间暖光

适用图像：火山、篝火、城市灯火、夜景、强局部光源。

```text
目标风格：低调暖光。整体曝光压低，保留大面积深暗背景，让熔岩、灯光、火光或云层高光成为唯一视觉中心。暗部保持黑蓝或深褐，边缘不过分提亮。暖色高光需要强烈、浓郁、带橙红层次，但必须保留细节纹理，不能变成纯色块。局部增加对比、清晰度和发光感，整体控制噪点和色带。画面应有黑暗包围光源的戏剧性，而不是全局提亮。
```

关键调图词：

- 阴影：近黑、深蓝黑、火光外缘保细节
- 中间调：暗褐、烟雾红、低饱和
- 高光：橙红、熔岩、灯芯式亮点
- 禁忌：暗部死黑无层次、红色溢出、火光糊成色块

## 风格族 04：城市蓝橙夜景

适用图像：城市天际线、桥梁、车流、夜景建筑、雨后街景。

```text
目标风格：城市蓝橙夜景。建筑阴影和天空向深蓝、青蓝靠拢，街灯、车流和窗光保持金橙色，形成明确蓝橙对比。压低天空亮度，增强城市灯光的局部亮度和清晰度；保留玻璃幕墙的冷色反射和线条感。高光不过曝，霓虹不过饱和，暗部不能脏灰。整体应干净、锐利、现代、带长曝光流动感。
```

关键调图词：

- 阴影：深蓝、青黑、清透
- 中间调：钢蓝、冷灰、玻璃反光
- 高光：金橙灯光、车流线、局部发光
- 禁忌：城市灰雾脏、灯光糊、蓝色过电光

## 风格族 05：湿润森林与绿色保护

适用图像：森林、蕨类、苔藓、瀑布、溪流、雨林、树冠。

```text
目标风格：湿润森林。保留绿色的层次和生命力，让暗部偏冷但不灰脏，亮部带柔和黄绿色阳光。增强苔藓、树皮、蕨类和水汽的局部纹理，同时让远处雾气保持柔和。绿色应有深绿、苔绿、黄绿的分层，避免统一刷成荧光绿或脏军绿。水流可增加长曝光柔滑感，白色水花保持干净不过曝。
```

关键调图词：

- 阴影：冷绿、深青绿、有湿度
- 中间调：苔绿、橄榄绿、自然饱和
- 高光：柔和黄绿、林间光束
- 禁忌：绿色变脏、荧光绿、树叶糊成一片

## 风格族 06：沙丘/纹理/抽象地貌

适用图像：沙丘、岩纹、地貌纹理、航拍抽象图、泥裂纹。

```text
目标风格：抽象地貌纹理。强化侧光造成的明暗起伏，提升纹理边缘和重复图案的节奏感。色彩以暖金、赭石、铜橙、冷蓝阴影构成对比，保持自然材料质感。避免过度锐化导致边缘发脏，也避免全局降噪抹掉细节。让画面呈现图案化、雕塑感和空间纵深。
```

关键调图词：

- 阴影：冷褐、蓝灰、细节清楚
- 中间调：沙金、赭石、铜橙
- 高光：侧光亮边、微暖
- 禁忌：纹理过锐、颜色塑料、暗部一团黑

## 风格族 07：黑白/低饱和雾景

适用图像：雾林、瀑布、雪山、孤树、极简海景、黑白风光。

```text
目标风格：低饱和雾景。大幅降低饱和度，保留微弱冷暖倾向；用亮度层次而不是颜色表达空间。黑位柔和下压，白位保留空气感，高光不纯白死亮。增强主体轮廓和近景纹理，远景雾化、低对比、轻微泛蓝或暖灰。整体应安静、极简、通透，不能变成灰蒙蒙的低对比废片。
```

关键调图词：

- 阴影：柔黑、冷灰、保轮廓
- 中间调：雾灰、银灰、低饱和
- 高光：柔白、乳白、空气感
- 禁忌：灰雾脏、主体消失、对比不足

## 风格族 08：星空/银河/极光

适用图像：夜空、银河、极光、夜间剪影、湖面倒影。

```text
目标风格：深夜星空。天空背景压到深蓝黑，保留星点和银河尘埃的层次。银河区域提升局部对比、清晰度和微弱紫蓝/青绿色彩，但避免过度锐化和噪点彩斑。地景保持剪影或轻微冷调细节，不喧宾夺主。若有极光，让绿色和青色明亮但不荧光，边缘保持云雾般柔软。整体应深邃、干净、带宇宙尺度感。
```

关键调图词：

- 阴影：深蓝黑、干净、低噪
- 中间调：银河紫蓝、极光青绿
- 高光：星点清晰、不过曝
- 禁忌：星空过紫、噪点彩斑、地景提亮过度

## 风格族 09：海岸长曝光

适用图像：礁石、海浪、瀑布、溪流、云流动、潮汐。

```text
目标风格：海岸长曝光。水流和云层呈丝绸般平滑运动，礁石、山体和主体保持清晰稳固。阴影偏冷，海水带蓝青或银灰，高光保持柔和流动，不要让浪花爆白。增强前景引导线和水流方向，让视觉自然进入主体。整体应梦幻、流动、有力量，但仍然保留真实摄影质感。
```

关键调图词：

- 阴影：深蓝、湿润、岩石纹理
- 中间调：蓝青、银灰、水流柔滑
- 高光：浪花柔白、有层次
- 禁忌：水面假糊、礁石过软、白浪爆掉

## 风格族 10：主体剪影与边缘光

适用图像：人物小剪影、树、山脊、岩洞、建筑轮廓、日食/强逆光。

```text
目标风格：剪影边缘光。主体可以保持接近剪影，但轮廓必须清晰，边缘光要自然地勾出形体。背景高光有层次，不允许中心光源爆成无细节白块。阴影不必强行提亮，重点是形状、空间关系和光源方向。色彩可使用冷暗背景与暖光边缘对比，整体简洁、戏剧化、具有标志性轮廓。
```

关键调图词：

- 阴影：剪影、深黑蓝、轮廓明确
- 中间调：低饱和、保空间
- 高光：边缘光、日晕、方向明确
- 禁忌：主体边缘糊、高光纯白、剪影缺形

## 组合调用模板

```text
参考风格族：{风格族名称}
目标：将原图迁移为{一句话风格目标}
光影：{阴影要求}；{中间调要求}；{高光要求}
色彩：{主色关系}；{冷暖关系}；{饱和度策略}
局部保护：保护肤色、绿色、天空、橙黄主体和主视觉中心；禁止脏绿、假蓝、死黑和爆白
输出：A_light 轻度、B_standard 标准、C_strong 强风格；默认推荐 B_standard
验收：光影平均分 >= 90，色彩平均分 >= 95，9 点 RGB 采样至少 8 点达标、5 点严格达标
```

## 精细风格卡

以下风格卡用于实际选择提示词。每次只选 1 张主卡，必要时叠加 1 张辅助卡。

### 卡 01：深蓝海岸长曝光

适用：海岸、礁石、潮汐、低角度海景、阴天海面。

```text
审美目标：深蓝海岸长曝光，画面像被冷色空气包裹，水流柔滑但岩石坚实。整体中低调，前景礁石有重量，远处海天有雾化层次，浪花高光柔白而不爆。
亮度曲线：黑位轻压，阴影保岩石纹理；中间调向下收一点，让水流和天空更安静；高光只保留在浪花、云边和水面反光。
颜色配方：阴影深蓝/青黑；水面蓝青/银灰；高光淡蓝白；若有日落，高光可带极轻微金色，但不能全图变暖。
质感：水流丝绸感，云层有方向性拖影，岩石边缘清楚但不过锐。
局部 mask：水体单独柔化，岩石单独保清晰，天空单独压饱和，白浪单独保护高光。
负向约束：不要假长曝光糊全图；不要让礁石变软；不要让白浪纯白；不要把海水调成荧光青。
```

### 卡 02：冷蓝雾山史诗感

适用：山脉、峡谷、云海、冰川、远景雾化风光。

```text
审美目标：冷蓝雾山史诗感。近景有暗部重量，远景被蓝灰空气层包裹，山脊和云边形成微弱但明确的视觉路径。
亮度曲线：低调 S 曲线；近景阴影深，中景中间调有体积，远景对比降低；高光集中在云缝、山脊、雪线或天空裂口。
颜色配方：阴影蓝黑/紫灰；中间调冷灰蓝；远景淡青灰；高光银白或微暖白。
质感：近景岩石和山体保局部对比，远景雾气保柔；云层要有体积，不要成为一片灰。
局部 mask：远景降低清晰度和饱和度，近景提升微对比，高光云边单独压保护。
负向约束：不要把山体压成死黑；不要让雾气发脏；不要让天空变成过饱和蓝。
```

### 卡 03：金橙逆光空气感

适用：日出日落、逆光花草、海岸夕阳、山谷霞光、城市晨昏。

```text
审美目标：金橙逆光空气感。光像穿过空气、雾气或草叶，暖色只落在受光区域，暗部仍然深而冷，画面有呼吸感和纵深。
亮度曲线：高光柔推但压住白点；中间调略暖并保过渡；阴影下压到蓝紫灰，形成冷暖对冲。
颜色配方：高光金橙/蜂蜜色；亮中间调暖褐/浅琥珀；阴影蓝紫/冷灰；绿色只允许被轻微暖化，不能发黄发脏。
质感：逆光边缘、空气颗粒、草叶或云层轮廓要细腻；不要强锐化。
局部 mask：太阳附近高光保护，主体边缘光增强，前景暗部保轮廓，橙黄主体保色。
负向约束：不要全局黄色滤镜；不要太阳爆白；不要人物肤色蜡黄；不要绿色变枯黄。
```

### 卡 04：火山熔岩低调戏剧感

适用：熔岩、火山、火光、强暖点光源、夜间暖光场景。

```text
审美目标：火山熔岩低调戏剧感。黑暗包围暖光，橙红高光像从画面内部发光，烟雾和岩石保持压迫感。
亮度曲线：整体曝光下压；黑场占比高但保边缘；高光峰值集中在熔岩/火光核心；中间调只保必要烟雾和地形。
颜色配方：黑蓝/炭黑背景；橙红/朱红/金黄高光；烟雾暗褐或紫灰；避免红色通道溢出。
质感：熔岩纹路清楚，火光有层次，烟雾柔而厚，岩石粗糙。
局部 mask：熔岩高光保纹理，烟雾保层次，暗部边缘轻微提取，红橙区域限制溢色。
负向约束：不要把火光涂成纯橙块；不要把暗部全黑；不要让红色溢出边界。
```

### 卡 05：城市蓝橙雨夜

适用：城市天际线、桥梁、街道、车流、雨后反光、玻璃建筑。

```text
审美目标：城市蓝橙雨夜。冷色建筑与暖色灯光分离明确，画面干净、锐利、现代，路面或玻璃有反光层次。
亮度曲线：天空和建筑阴影压暗；灯光高光局部提亮但限幅；街道中间调保持可读；反光区域保渐变。
颜色配方：天空深蓝/青蓝；建筑钢蓝/冷灰；灯光金橙/暖白；霓虹只做点睛色。
质感：玻璃线条锐，车流可有长曝光线条，雨后反光柔亮。
局部 mask：灯光限高光，建筑立面保垂直线条，天空降饱和，路面反光保细节。
负向约束：不要城市灰雾脏；不要灯光糊成块；不要全图赛博蓝紫。
```

### 卡 06：湿润苔绿森林

适用：森林、苔藓、蕨类、溪流、瀑布、雨林、树冠。

```text
审美目标：湿润苔绿森林。绿色不是一种颜色，而是深绿、苔绿、黄绿、冷灰绿的层次；画面有水汽、泥土和柔光。
亮度曲线：阴影柔暗，不能死黑；中间调保叶片和树干体积；高光只在林间光、湿叶反光、水花出现。
颜色配方：深部冷绿/青绿；受光处黄绿；树干暖褐；水体银白或冷青。
质感：叶片微对比，苔藓柔密，树皮粗糙，水汽柔。
局部 mask：绿色分区处理，水流高光保护，树干保暖褐，远处雾气降清晰。
负向约束：不要荧光绿；不要脏军绿；不要树叶糊成一片；不要白水爆掉。
```

### 卡 07：沙丘侧光雕塑感

适用：沙丘、岩层、干裂土地、航拍纹理、抽象地貌。

```text
审美目标：沙丘侧光雕塑感。光线像刀一样切出纹理起伏，画面有金属般的暖冷对比和图案节奏。
亮度曲线：侧光高光干净，阴影形状明确；中间调承接纹理，不要过平；整体可略低调以增加雕塑感。
颜色配方：高光沙金/浅铜；中间调赭石/暖褐；阴影冷褐/蓝灰。
质感：纹理清楚、重复图案有节奏，但边缘不能过锐发脏。
局部 mask：高光纹理限亮，阴影纹理保细节，重复线条提升局部对比。
负向约束：不要塑料橙；不要把纹理锐化成噪点；不要让阴影堵死。
```

### 卡 08：极简雾白孤独感

适用：孤树、雾林、冰雪、极简海景、低饱和高调图。

```text
审美目标：极简雾白孤独感。画面靠留白、柔雾和主体轮廓成立；颜色极少，亮度层次极细。
亮度曲线：黑位轻柔，不追求强黑；白位压住，保乳白层次；中间调平滑，主体轮廓略增强。
颜色配方：银灰、乳白、淡蓝灰、极轻微暖灰；饱和度很低。
质感：远景柔化，近景主体边缘清晰但不锐，雾气透明。
局部 mask：主体轮廓单独增强，背景降低对比，高光压层次。
负向约束：不要灰蒙蒙；不要主体消失；不要把高调做成死白。
```

### 卡 09：银河深夜清透感

适用：银河、星空、极光、夜间湖面、山体剪影。

```text
审美目标：银河深夜清透感。夜空深而透明，银河和星点细密，地景安静地支撑天空。
亮度曲线：天空背景压到深蓝黑；星点小高光保锐；银河中间调增强局部对比；地景保持低亮度。
颜色配方：背景深蓝/蓝黑；银河紫蓝/银灰；极光青绿；地景冷灰或剪影。
质感：星点干净，银河尘埃有层次，噪点控制自然。
局部 mask：天空降噪和局部对比分开，星点保小，地景不抢亮度，极光防荧光。
负向约束：不要星点膨胀；不要天空过紫；不要噪点彩斑；不要地景提亮过度。
```

### 卡 10：高反差剪影边缘光

适用：人物剪影、孤树、洞穴、山脊、日食、强逆光主体。

```text
审美目标：高反差剪影边缘光。主体可以暗，但形状必须有辨识度；边缘光自然勾勒轮廓，背景高光有层次。
亮度曲线：主体内部低亮度，边缘光和背景高光承担视觉中心；暗部保边界，不强行恢复全部细节。
颜色配方：主体深蓝黑/冷黑；背景可金橙、银白、蓝灰；边缘光随光源色变化。
质感：轮廓干净，边缘光窄而柔，背景过渡自然。
局部 mask：主体轮廓保护，光源高光限幅，边缘光微增强。
负向约束：不要描边感；不要主体糊边；不要背景爆白；不要剪影没有形。
```

## 美感增强词库

可按需加入，但不能替代具体光影指令：

- 空气感：薄雾、层层递远、透明水汽、远景低对比、柔和散射。
- 电影感：中低调、局部视觉中心、冷暖分离、克制饱和、暗部密度。
- 史诗感：大尺度空间、深暗前景、云层开口光、山脊层次、远近纵深。
- 静谧感：低饱和、柔高光、慢速水面、留白、主体孤立。
- 能量感：局部高光、橙红核心、强边缘光、暗背景包围光源。
- 湿润感：冷绿暗部、柔反光、水汽、苔藓细节、低对比远景。
