# 调图执行提示词库

用途：给图像处理 agent 或修图 agent 使用，描述从原图到 A/B/C 版本的实际调整顺序、保护规则、评分输出和失败回退。

## 总执行提示词

```text
输入一张原图和一张参考图后，先分析参考图的光影结构、主色关系、冷暖分离、饱和度、局部高光和受保护颜色；再诊断原图差异。处理顺序必须是：光影匹配 -> 色彩迁移 -> 局部保护 -> A/B/C 强度分版 -> 评分 -> RGB 采样 -> 中文报告。不要使用单一滤镜覆盖全图。每一步都要保护主体、肤色、绿色、天空、橙黄主体和关键高光纹理。
```

## 色彩迁移提示词

### 冷暖分离

```text
把阴影和部分中间调推向冷蓝/青蓝/紫灰，把高光和受光区域推向金橙/琥珀/暖白，形成参考图的冷暖分离。冷暖分离必须依赖亮度区间和局部光源，不得全局双色调硬套。保持中性灰区域不过度偏色。
```

### 低饱和电影感

```text
降低全局杂色饱和度，只保留关键色的局部饱和：夕阳橙、火山红、城市灯金、森林苔绿、海水青蓝、极光绿。整体颜色要干净、克制、有方向，避免一键鲜艳。
```

### 主色提纯

```text
识别参考图主色和辅助色，减少无关杂色。主色可更纯，辅助色保持低饱和，背景色服从主体色。不要让所有颜色都同等抢眼。
```

## 局部保护提示词

### 肤色保护

```text
如果画面有人物，肤色优先保护。肤色不能被推成绿色、灰色、橙红或蜡黄。人物可以接受环境光轻微影响，但面部和裸露皮肤必须保留自然血色和亮度层次。
```

### 绿色保护

```text
绿色区域必须保持层次：深绿、苔绿、黄绿、灰绿分开处理。避免绿色整体变脏、变荧光或偏黄。森林暗部可以冷，但不能把叶片推成灰黑。
```

### 天空保护

```text
天空可以冷蓝、青蓝、紫蓝或金橙，但必须符合参考图光源和天气。禁止假蓝、色带、过饱和青色和云层脏灰。保留云层明暗纹理和远近层次。
```

### 橙黄主体保护

```text
橙黄主体如花、沙丘、岩石、灯光、火光、落日边缘需要保留色彩能量。不能因为冷调迁移而丢失橙黄主体，也不能因为暖调迁移而让全图发黄。橙黄只应集中在主体和受光区域。
```

### 水体保护

```text
海水、瀑布、溪流和雾化水面保持蓝青、银灰或柔白层次。长曝光质感可以柔化水流，但岩石和固定主体应保持清晰。白水高光不能爆，深水阴影不能脏。
```

## 风格化强度提示词

### A_light 轻度版

```text
A_light：只做 30%-45% 参考图迁移。保持原图自然曝光和真实色彩，轻微压暗阴影、微调高光色温、降低杂色饱和度。适合需要保守交付和自然商业使用的版本。
```

### B_standard 标准版

```text
B_standard：做 55%-75% 参考图迁移。光影明显接近参考图，冷暖关系清楚，关键色更集中，主体保护完整。它是默认推荐版本，要求在风格强度和自然度之间取得平衡。
```

### C_strong 强风格版

```text
C_strong：做 80%-95% 参考图迁移。更强低调、更强局部高光、更明显冷暖分离和主色提纯。必须严格检查高光爆掉、阴影死黑、绿色脏、天空假蓝和滤镜感；任何一项出现就降低强度。
```

## 按场景调用模板

### 海岸/瀑布

```text
优先匹配参考图的水面亮度和流动感。阴影偏冷，岩石保留纹理，水流高光柔白不过曝。增强前景引导线，避免水面糊成一片。
```

### 山地/云雾

```text
建立远近空气透视：近景对比更强，远景更低对比、更冷、更雾化。山体阴影保持蓝灰层次，高光只在云边和山脊集中。
```

### 森林/雨林

```text
保持绿色层次和湿润质感。暗部冷绿但不脏，林间高光柔和偏黄绿。增强叶片、树皮、苔藓、水汽细节，禁止荧光绿。
```

### 城市夜景

```text
压暗天空和建筑阴影，让灯光、车流和窗光成为高光中心。建筑保持钢蓝/青灰，灯光保持金橙，控制霓虹过饱和。
```

### 星空/极光

```text
天空背景深蓝黑，星点清晰，银河和极光局部增强。降低噪点和色斑，地景保持剪影或低亮度细节，不抢天空主体。
```

### 沙丘/纹理

```text
强化侧光纹理和重复图案。暖色中间调配冷色阴影，保留材料质感。避免过锐、过橙和暗部死黑。
```

## 评分与验收提示词

```text
输出前必须评分。评分必须读取真实原图、参考图（如有）和 A/B/C 输出图的像素数据后计算，不能凭提示词或主观感觉填写。光影四项：阴影、中间调、高光、整体。色彩四项：主色匹配、冷暖关系、饱和度控制、局部颜色保护。有参考图时，光影平均分必须 >= 90，色彩平均分必须 >= 95。RGB 采样取 9 个点：阴影 3 个、中间调 3 个、高光 3 个；采样点必须是真实图片坐标，至少 8 点达标，至少 5 点严格达标。无参考图时，改为记录原图到结果的 9 点 RGB 变化、亮度/饱和度/剪切比例等技术检查。若出现高光爆、阴影死黑、肤色偏绿偏灰、绿色变脏、天空假蓝、橙黄主体丢失或滤镜感，直接判不通过。
```

## 真实调图约束

```text
A/B/C 必须是对原图实际像素处理后的结果，不能重新生成一张新图片来替代原图。允许曲线、色彩空间转换、局部 mask、亮度匹配、色彩匹配、锐化、降噪和局部 dodge/burn。禁止用文生图/图生图直接生成“风格化新图”冒充调图结果。所有评分文件必须记录真实输入路径、输出路径、采样坐标、统计值和计算依据。
```

## RAW 显影提示词

```text
如果输入是 RAW，不要把 RAW 当普通 JPG/PNG 处理。先保留 RAW 原文件，再用 RAW 解码工具显影为 16-bit TIFF 中间文件。显影阶段优先保留动态范围：高光不过早压死，阴影不过早抬灰，白平衡保持可调整余量。后续 A/B/C 调图、评分和 RGB 采样都基于显影后的真实 16-bit TIFF 像素继续处理。scores.json 必须记录 RAW 路径、显影中间文件路径、解码工具和显影参数。如果无法解码 RAW，停止报告，不得用嵌入预览图冒充 RAW 处理结果，除非用户明确同意。
```

## 失败回退提示词

```text
如果结果像滤镜：降低全局色彩强度，改为亮度分区和局部 mask 迁移。
如果高光爆掉：降低白位和高光增益，恢复云层/水面/灯光纹理。
如果阴影死黑：抬升局部阴影细节，但不要抬灰整张图。
如果绿色变脏：减少青色污染，恢复黄绿和深绿分层。
如果天空假蓝：降低蓝色饱和度和青色偏移，恢复云层灰度。
如果肤色异常：对肤色区域单独回退色相和饱和度，保留自然血色。
如果橙黄主体丢失：恢复主体暖色亮度和局部饱和度，限制冷调覆盖范围。
```

## 精细调图流程提示词

### Step 1：参考图拆解

```text
先拆解参考图，不做任何输出：判断参考图的题材、光源方向、影调分布、黑场面积、高光位置、主色、辅色、点睛色、空气感、材质和保护对象。把参考图拆成“可迁移的光影逻辑”和“不可迁移的场景内容”。只迁移光影、色彩和质感倾向，不把参考图不存在于原图的物体硬迁移过去。
```

### Step 2：原图诊断

```text
诊断原图与参考图的差距：原图是否太亮、太平、太灰、太黄、太绿、太蓝；高光是否已有溢出；阴影是否已有死黑；主体是否不够突出；天空、绿色、肤色、橙黄主体是否需要保护。先解决原图硬伤，再做风格迁移。
```

### Step 3：光影优先

```text
先让原图接近参考图的亮度结构：黑场面积、阴影密度、中间调体积、高光位置、局部对比和视觉中心。此阶段不要强推色彩；只允许轻微色温辅助判断明暗。
```

### Step 4：色彩分区

```text
按亮度和语义区域迁移色彩：阴影色、中间调色、高光色、主体色、背景色、点睛色分别处理。不要全局统一覆盖色相。优先保持自然材质：天空像天空，水像水，叶子像叶子，皮肤像皮肤。
```

### Step 5：局部精修

```text
最后做局部 mask：主体提取、天空保护、绿色保护、肤色保护、橙黄主体保护、水体保护、高光保护。每个 mask 的目标是“更接近参考图但不破坏真实感”。
```

## 色彩配方卡

### 蓝青阴影 + 金橙高光

```text
阴影向深蓝、青蓝或紫灰移动，高光向金橙、暖白或琥珀移动，中间调保持过渡。冷色主要存在于暗部，暖色主要存在于受光处。避免全图青橙滤镜，避免中性灰被污染。
```

### 银灰低饱和

```text
降低全局饱和度，保留银灰、蓝灰、乳白和少量暖灰。用亮度层次表达空间，不依赖鲜艳颜色。适合雾景、冰雪、极简海景。必须保护主体轮廓，避免灰蒙蒙。
```

### 深绿湿润

```text
绿色按亮度拆分：深阴影为冷绿/青绿，受光叶片为黄绿，苔藓为柔和饱和绿，树干为暖褐。降低脏青和荧光绿，保留叶片之间的明暗差。
```

### 火光橙红

```text
暖光核心使用金黄、橙红、朱红分层，外围过渡到烟雾褐和深蓝黑。红橙只服务火光或熔岩主体，不扩散到整张图。保护红色通道细节。
```

### 城市钢蓝金橙

```text
天空和建筑使用钢蓝、深蓝、冷灰，灯光和车流使用金橙、暖白。降低杂色霓虹，保留线条和反光。蓝橙分离要干净，不要紫红污染。
```

## 局部保护精修卡

### 天空精修

```text
天空按云层和晴空分开处理。晴空降低蓝色饱和和青色偏移，避免假蓝；云层保留亮暗边和体积，避免灰脏；日落天空保留暖色渐变，不要色带。天空不应抢走主体，除非参考图的主体就是天空。
```

### 绿色精修

```text
绿色先去脏，再分层。去掉多余青灰和黄泥感，恢复深绿、苔绿、黄绿的层次。叶片亮部可以稍暖，阴影可以稍冷。禁止一键加饱和，禁止把绿色压成同一种颜色。
```

### 肤色精修

```text
肤色单独 mask。肤色允许受环境光轻微影响，但必须保留自然红黄比例。冷调风格下，肤色只略降饱和和亮度，不得偏绿偏灰；暖调风格下，不得蜡黄或橙红。
```

### 橙黄主体精修

```text
橙黄主体如花、岩石、沙丘、灯光、落日边缘需要保持视觉能量。冷调迁移时限制冷色覆盖主体；暖调迁移时限制暖色扩散背景。橙黄主体要有亮度和饱和度，但不能过曝或荧光。
```

### 水体精修

```text
水体分为深水、白浪、反光和流动方向。深水可冷蓝青，白浪柔白有细节，反光保渐变，流动方向可柔化。不要把水体整体降噪成塑料，也不要让白浪纯白。
```

### 星点与灯光精修

```text
星点和城市灯都是小面积高光，必须小、亮、清楚。提亮时限制半径，避免膨胀成光斑。灯光可有轻微光晕，星点不应有大光晕。
```

## A/B/C 精细差异

```text
A_light：
- 光影迁移 30%-45%，色彩迁移 25%-40%
- 保持原图自然，主要修正曝光、对比、杂色和轻微冷暖
- 局部保护强于风格化

B_standard：
- 光影迁移 55%-75%，色彩迁移 50%-70%
- 明确接近参考图的影调和主色关系
- 主体、天空、绿色、肤色保护必须完整
- 默认推荐

C_strong：
- 光影迁移 80%-95%，色彩迁移 70%-90%
- 允许更强低调、更强冷暖、更高局部对比
- 一旦出现滤镜感、假蓝、脏绿、爆白、死黑，立即回退到 B 与 C 之间
```

## 美感打磨提示词

```text
让画面有“主次”：主体最清楚、次要区域服务主体、边缘安静。
让画面有“呼吸”：远景不抢，雾气和天空有柔和过渡。
让画面有“密度”：暗部有重量，但不是一团黑。
让画面有“材质”：水柔、岩石硬、云厚、叶片湿、建筑冷、星点小。
让画面有“克制”：只让关键色饱和，其余颜色退后。
让画面有“方向”：光源方向、引导线和冷暖关系一致。
```

## 组合式执行模板

```text
请根据图片判断框架先判断原图和参考图，然后选择对应风格卡、光影卡和调图卡。保持调图和光影主流程不变，不改变验收阈值。

本次选择：
- 主风格卡：
- 辅助风格卡：
- 曲线卡：
- 色彩配方卡：
- 局部保护卡：
- 失败回退卡：

执行：
1. 先匹配参考图亮度结构。
2. 再迁移参考图色彩关系。
3. 对主体、天空、绿色、肤色、橙黄主体、水体和小高光做局部保护。
4. 输出 A_light、B_standard、C_strong。
5. 读取实际输出图做真实评分；有参考图时用光影 >= 90、色彩 >= 95、9 点 RGB 采样和一票否决检查验收；无参考图时输出真实像素统计、9 点前后采样、提示词匹配度、光影质量、色彩质量、局部保护和技术检查。
```
