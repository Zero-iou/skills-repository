# 光影迁移提示词库

用途：给参考图光影迁移智能体使用，专门描述亮度、对比、阴影、中间调、高光、局部光源和一票否决检查。

## 光影总原则

```text
先迁移光影，再迁移颜色。不要先套色彩滤镜。以参考图的亮度分布为目标，分别匹配阴影、中间调、高光和整体对比。暗部要深，但必须保留主体边缘、材质纹理和空间层次；高光要有视觉中心，但不能爆白；中间调要负责画面的体积和空气透视。所有调整必须避免 HDR 脏灰、过度锐化、阴影死黑和高光爆掉。
```

## 阴影提示词

### 深暗但有细节

```text
将阴影压向深蓝黑或深冷灰，保持低调氛围；不要把暗部整体抬灰。保留近景纹理、主体轮廓和关键过渡，让阴影有密度、有方向、有层次。黑位可以下压，但最暗区域仍需可分辨边缘，禁止死黑成块。
```

### 冷调阴影

```text
阴影区域偏冷蓝、青蓝或紫灰，用冷色承接画面深度。冷色只作用于阴影和部分中间调，不污染高光。避免阴影变成脏青、脏绿或数码蓝。
```

### 暖光阴影保留

```text
在火山、夕阳、城市灯光或烛光场景中，暗部仍保持低亮度，但允许靠近光源的阴影边缘带轻微暖红、暖褐或橙色反射。暖色只出现在受光边缘，不要全局泛橙。
```

## 中间调提示词

### 山体/云雾中间调

```text
中间调承担山体、云雾、海面和远景的层次。降低杂乱对比，保留柔和过渡；近景中间调可增加局部对比，远景中间调应更低对比、更雾化，以形成空气透视。
```

### 城市/建筑中间调

```text
中间调保持建筑线条、玻璃反射和街道结构清晰。冷灰、钢蓝和轻微青色可以增强现代感，但不能让建筑发脏。局部提高清晰度和对比，保持边缘干净。
```

### 森林中间调

```text
中间调保留树叶、苔藓、树干和水汽层次。绿色分成深绿、苔绿、黄绿和灰绿，不允许统一成一片。提升叶片和树皮的微对比，但远处雾气保持柔软。
```

## 高光提示词

### 太阳/逆光高光

```text
太阳附近高光要暖、亮、有扩散，但不能纯白爆掉。保留日晕、云层边缘和逆光轮廓。用局部高光引导视线，不要把整张图提亮。
```

### 水流/浪花高光

```text
水流和浪花高光保持柔白、银白或淡蓝白，有细节层次。长曝光水面可以柔滑，但岩石和主体不能被柔化。白浪不能爆白，水面不能变塑料。
```

### 城市灯光高光

```text
灯光高光保持金橙或暖白，增强局部发光和车流线条。控制灯牌和窗光的峰值亮度，避免糊成一团。冷色建筑和暖色灯光要分离清楚。
```

### 星空高光

```text
星点高光要小、清晰、干净，不要扩大成噪点。银河亮部保留尘埃结构，局部增强对比但控制锐化。地景高光只能轻微辅助，不能抢走天空主体。
```

## 对比曲线提示词

### 低调高对比曲线

```text
使用低调高对比曲线：黑位下压、阴影保细节、中间调略暗、高光局部抬升。让画面形成“暗背景包围亮主体”的视觉结构。禁止全局 HDR 提亮。
```

### 柔雾低对比曲线

```text
使用柔雾低对比曲线：黑位轻微抬起但不灰，高光压柔，中间调过渡平滑。适合雾林、冰雪、海雾和极简场景。保留主体轮廓，避免画面失焦或发灰。
```

### 金色逆光曲线

```text
使用金色逆光曲线：高光暖而柔，中间调保体积，阴影冷而深。太阳或光源附近增加渐变扩散，前景保留暗部形状。避免全局泛黄。
```

## 局部光提示词

### 边缘光

```text
增强主体受光边缘，让边缘光自然勾勒轮廓。边缘光必须符合参考图光源方向，不能像描边。亮边宽度要窄，过渡要柔和，主体内部仍保持合理明暗。
```

### 光束和空气感

```text
如果画面有雾气、森林、云层或尘埃，增强光束的方向和空气透视。光束要柔、透明、有渐变，不能变成硬白条。雾气应参与空间分层，而不是覆盖全图。
```

### 暗角与视觉中心

```text
使用自然暗角强化视觉中心。暗角只压低边缘注意力，不应让角落死黑或出现明显滤镜边界。中心主体亮度、对比和色彩略高于周围。
```

## 一票否决检查提示词

```text
完成光影迁移后逐项检查：高光是否爆掉；阴影是否死黑；中间调是否发灰；主体轮廓是否丢失；天空或水面是否出现断层；暗角是否像滤镜；局部清晰度是否过锐。任一问题出现，当前版本判为不通过并回退调整。
```

## A/B/C 光影强度模板

```text
A_light：保守迁移。阴影轻压，高光轻微匹配参考图，中间调自然，局部对比提升较少，优先保真。
B_standard：标准迁移。阴影、中间调、高光按参考图明显靠近，保留自然感，是默认推荐版本。
C_strong：强风格迁移。更低黑位、更强冷暖分离、更集中的高光和更强局部对比，但仍必须通过高光、阴影和主体保护检查。
```

## 亮度区间精细控制

用于把“光影好看”拆成可执行区域：

```text
黑场 0%-5%：只用于画面重量、剪影深处和极深缝隙。面积不能过大，不能吞掉主体边缘。
深阴影 5%-18%：建立低调氛围，保留轮廓和材质边界。允许偏蓝黑、紫灰或冷褐。
浅阴影 18%-32%：负责暗部可读性，是防止死黑的关键区。需要轻微局部对比。
暗中间调 32%-48%：负责体积、山体、建筑、树干、水面暗面。不能一味压暗。
亮中间调 48%-72%：负责主体表面、云层体积、雾气层次。需要平滑过渡。
高光 72%-90%：负责视觉中心、边缘光、云边、水花、灯光外缘。必须有细节。
极高光 90%-100%：只能小面积存在于太阳核心、星点、灯芯或镜面反光。禁止大面积纯白。
```

## 曲线选择卡

### 曲线 A：冷调低调 S 曲线

```text
选择冷调低调 S 曲线。黑场少量下压，深阴影增加密度，浅阴影保轮廓；中间调轻压，高光只在主体和天空裂口处抬升。适合山海、夜景、星空、城市和戏剧化风光。
```

### 曲线 B：柔雾压高光曲线

```text
选择柔雾压高光曲线。白位压柔，亮中间调保留乳白和银灰层次，黑位不硬压。适合雾林、雪景、冰海、极简孤树。重点是空间和留白，不是强对比。
```

### 曲线 C：暖光局部峰值曲线

```text
选择暖光局部峰值曲线。整体中低调，暖色高光局部达到峰值但保细节，阴影冷而深。适合日落、火山、城市灯光、逆光草地。暖光要像从局部发出，不是铺满全图。
```

### 曲线 D：纹理侧光曲线

```text
选择纹理侧光曲线。维持中间调密度，通过侧光高光和阴影边界增强材料起伏。适合沙丘、岩纹、树皮、航拍纹理。避免全局对比过强导致纹理噪点化。
```

## Dodging 与 Burning 提示词

### Dodge 视觉中心

```text
只在视觉中心、主体边缘、引导线末端、云层开口、水面反光或灯光外缘做局部 dodge。提亮幅度要渐变，不能出现刷痕。dodge 后仍需保留高光纹理。
```

### Burn 边缘与前景

```text
对画面边缘、无关天空、前景暗部和背景杂乱区域做轻微 burn，让注意力回到主体。burn 必须顺着自然光线和空间关系，不能形成明显暗角滤镜。
```

### 局部对比分层

```text
近景材质增加局部对比，中景保持体积，远景降低对比以形成空气透视。不要全图统一清晰度；雾、水、云、皮肤需要更柔，岩石、建筑、树皮、星点需要更清楚。
```

## 光影美感诊断

输出前逐项判断：

```text
视觉中心是否明确？如果不明确，优先局部 dodge 主体或压低背景。
暗部是否有重量？如果太灰，压深黑场和深阴影，但保护主体边缘。
暗部是否死黑？如果死黑，只恢复浅阴影和轮廓，不全局抬曝光。
高光是否有层次？如果爆白，压白位和高光峰值，恢复云边/水花/灯光纹理。
中间调是否脏？如果脏，降低杂色饱和，分离冷暖，减少 HDR 式清晰度。
远景是否有空气透视？如果没有，降低远景对比、饱和和清晰度。
材质是否被统一处理？如果统一，按水/云/岩石/树叶/建筑分别处理。
```

## 场景光影微提示词

### 海岸

```text
前景礁石压暗但保湿润纹理，水流亮中间调柔化，高光浪花限幅，远处海天降低对比。让水流方向成为视觉路径。
```

### 山谷云海

```text
近景山体深暗，中景云雾保体积，远景冷灰低对比。高光只出现在云缝、山脊和远处光源。
```

### 森林

```text
林下阴影柔暗，叶片中间调分层，林间光高光柔而窄。不要把森林整体提亮，湿润感来自暗部和微反光。
```

### 城市夜景

```text
天空和建筑阴影压低，灯光局部提亮并限幅，玻璃反射保持冷灰蓝线条。车流和路面反光可以柔亮，但不能糊。
```

### 星空

```text
夜空背景深蓝黑，银河亮部局部增强，星点小而清楚。地景只保剪影或极低亮度细节，不抢天空。
```
