# 提示词选择与优化规则

用途：在保持光影迁移和调图主流程不变的前提下，为不同图片选择更精确的提示词组合。支持两种模式：有参考图时做参考图迁移；无参考图时根据原图自动选择风格卡做单图自动风格迁移。

## 不可改变的主流程

无论选择哪一组提示词，都不能改变以下顺序：

1. 分析参考图；如果无参考图，则分析原图并自动选择目标风格
2. 诊断原图与目标风格的差距
3. 先迁移光影
4. 再迁移色彩
5. 做局部保护
6. 生成 A/B/C
7. 评分、RGB 采样、验收、报告

提示词只能优化“判断角度、风格描述、局部保护、失败回退”，不能降低有参考图模式下的光影 `>= 90`、色彩 `>= 95`、9 点 RGB 采样和一票否决标准。

无参考图时，不伪造参考图分数；改用提示词匹配度、光影质量、色彩质量、局部保护和技术检查。所有分数必须来自真实输出图的像素分析和采样，不得凭提示词直接打分。

## 模式判断

先判断任务模式：

```text
如果同时存在原图和参考图：
  模式 = 参考图光影色彩迁移
  目标 = 尽量接近参考图的光影、色彩和质感

如果只有原图，没有参考图：
  模式 = 单图自动风格迁移
  目标 = 根据原图题材、光影、色彩和材质自动选择最合适的风格卡，并对原图做实际像素调图
  必读 = auto_style_transfer_guide.md
```

## 选择顺序

有参考图时，按这个顺序选择提示词：

1. 从 `image_judgment_framework.md` 判断图片。
2. 从 `reference_style_prompt_library.md` 选择 1 个主风格族，最多 1 个辅助风格族。
3. 从 `lighting_prompt_library.md` 选择影调曲线、阴影卡、中间调卡、高光卡、局部光卡。
4. 从 `retouching_prompt_library.md` 选择色彩迁移卡、局部保护卡、A/B/C 强度卡和失败回退卡。
5. 组合成一次运行提示词。

无参考图时，按这个顺序选择提示词：

1. 从 `image_judgment_framework.md` 判断原图。
2. 从 `auto_style_transfer_guide.md` 的自动风格映射表中选出 2-3 个候选风格。
3. 按题材匹配、光源匹配、影调匹配、色彩匹配、材质匹配、失败风险低进行候选打分。
4. 从 `reference_style_prompt_library.md` 选择最高分风格卡作为主风格。
5. 如果第二名与第一名差距 `<= 8` 分，并且不冲突，可作为辅助风格。
6. 从 `lighting_prompt_library.md` 和 `retouching_prompt_library.md` 选择对应光影卡、色彩卡、局部保护卡和失败回退卡。
7. 组合成单图自动风格迁移提示词。

## 主风格与辅助风格

只允许一个主风格族，避免风格互相打架。

可用组合：

- 冷蓝雾化山海 + 海岸长曝光
- 金橙逆光 + 主体剪影
- 低调火山暖光 + 星空夜景
- 城市蓝橙夜景 + 低调高对比
- 湿润森林 + 长曝光水流
- 沙丘纹理 + 金橙侧光
- 低饱和雾景 + 极简主体

不推荐组合：

- 雪雾高调 + 低调火山暖光
- 湿润森林 + 沙漠金橙全局
- 星空深夜 + 高调雾景
- 城市蓝橙 + 森林黄绿主导

## 美感判断标准

选词后必须检查：

- 是否有明确视觉中心，而不是全图平均好看。
- 是否有深浅层次，而不是单纯暗或单纯亮。
- 是否有冷暖关系，而不是全局单色。
- 是否有局部保护，而不是统一滤镜。
- 是否有空气感和材质差异，而不是所有区域同样清晰。
- 是否像一次专业调色，而不是预设套用。

无参考图时还要检查：

- 自动选择的风格是否能从原图结构中自然成立。
- 是否没有硬造原图中不存在的光源、天空、雾气或长曝光效果。
- A/B/C 是否只是强度不同，而不是三种互相冲突的风格。
- 报告是否明确说明“参考图：无，使用单图自动风格迁移”。
